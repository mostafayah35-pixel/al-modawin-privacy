**On-Device Transcription**
In "On-Device" mode, audio is converted to text entirely within your phone without sending any data over the internet[span_9](start_span)[span_9](end_span). The internet is only used to download model files if you choose to do so[span_10](start_span)[span_10](end_span).

**Online Transcription (Optional)**
If you enable "Online" mode and provide your consent, your audio recording is sent via an encrypted connection (HTTPS) to your chosen provider: Groq or Cohere, using your API key[span_11](start_span)[span_11](end_span). This data is processed according to the provider's privacy policy[span_12](start_span)[span_12](end_span). Do not use this mode for sensitive content[span_13](start_span)[span_13](end_span). API keys are stored only on your device[span_14](start_span)[span_14](end_span).

**Smart Assistant (Optional)**
When you use the Assistant features (summarization, translation, correction, titles, tags, tasks), the selected note text is sent via an encrypted connection (HTTPS) to your chosen provider: Groq or Cohere, using your key, and after your explicit consent[span_15](start_span)[span_15](end_span). No text is sent automatically unless you enable the "Automatic Note Title" option[span_16](start_span)[span_16](end_span). Text processing is subject to the provider's privacy policy, so do not use the Assistant for sensitive content[span_17](start_span)[span_17](end_span).
